## Why this exists

**Every brand posts the same three shapes forever:** a square for the feed, a story, a
banner for the link preview. Every single time, someone opens a design app, hunts for last
month's file, eyeballs the colors, and exports something *almost* on-brand.

Define your theme **once, in code**. Then generate any format from the command line —
identical type ramp, identical accent, identical export settings, for free.

## One theme → every format

```bash
# Node is the only prereq (the Photopea MCP is fetched via npx on first run).
python scripts/post_factory.py square "NEW DROP" "Our biggest" "sale ever." "Up to 50% off." "Shop now" "@brand" square.png
python scripts/post_factory.py story  "BEHIND THE SCENES" "How we" "built it." "Swipe up." "" "@brand" story.png
python scripts/post_factory.py banner "ANNOUNCING" "v2 is here" "" "" "" "" banner.png
```

| Format | Size | For |
|---|---|---|
| `square` | 1080×1080 | Instagram / Facebook / LinkedIn feed |
| `story` | 1080×1920 | IG / FB / TikTok stories & reel covers |
| `banner` | 1200×630 | Open Graph, Twitter cards, blog headers |

A browser window opens (that's Photopea — expected); the post is composed and exported.

## Rebrand in 6 lines

Everything keys off one theme block in [`scripts/post_factory.py`](scripts/post_factory.py):

```python
THEME = {
    "bg1": "#16182e",   # gradient start
    "bg2": "#283276",   # gradient end
    "accent": "#f5d76e",# one accent color
    "ink": "#ffffff",   # primary text
    "mute": "#c9cde0",  # secondary text
    "angle": 120,
}
```

Change those five colors and **every** format follows your brand. One accent, a clean
two-step type ramp (eyebrow → hero → subtitle), warm palette — the design-system basics,
enforced in code instead of in a style guide nobody opens.
